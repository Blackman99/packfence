CLI

packfence [path] [--format human|json|github-annotations|summary]
          [--config file] [--list] [--test] [--fail|--no-fail]
FlagMeaning
--formatOutput style. Default human.
--configPath to JSON config (else .packfencerc.json / package.json#packfence).
--listAlso print every packed file path + size.
--testReport HOLD findings but exit 0.
--failExit 1 on fail findings (default).

Exit codes

CodeMeaning
0CLEAR, or --test
1HOLD (fail-severity finding)
2Usage / runtime error (e.g. npm pack failed)

GitHub Action

- uses: Blackman99/packfence@v0.1.0
  with:
    path: .
    config: ""
    fail: true
    version: local

version: local builds the action checkout. Set a semver once the package is on npm.

Config schema

{
  "allow": ["glob"],
  "deny": ["glob"],
  "severity": { "source-map": "fail", "file-large": "warn" },
  "maxFileBytes": 20971520,
  "maxFileWarnBytes": 5242880,
  "maxTotalBytes": 52428800,
  "contentScanMaxBytes": 524288
}

Severity values: fail · warn · info · allow.

How the file list is built

packfence shells out to npm pack --dry-run --json --ignore-scripts so the file set matches what npm would put in the tarball (npm-packlist / files field / .npmignore).
